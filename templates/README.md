# Como aplicar os templates

Os arquivos aqui servem como **fonte para copiar**, não são instruções automaticamente aplicadas ao código deste repositório de playbook.

1. Escolha `fed`, `bff` ou `srv`.
2. Copie a estrutura da pasta escolhida **para a raiz do repositório da aplicação**.
3. Copie os arquivos de `shared/.github/` para `.github/` do projeto, preservando estrutura.
4. Revise configurações existentes e faça merge manual, sem sobrescrever.
5. Substitua todos os `PREENCHER` pelos dados verificados do build/código em **ambiente autorizado**.
6. Abra PR nos repositórios de trabalho com revisão técnica e de segurança, quando aplicável.

O README principal oferece a sequência pedagógica. A disponibilidade de prompt files depende da IDE e da versão do GitHub Copilot.
