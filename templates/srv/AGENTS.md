# Mapa rápido para agentes — SRV / Squad Pitbull

- Leia `.github/copilot-instructions.md`; consulte `docs/ai-context.md` apenas se relevante.
- Foque somente módulos envolvidos na história; não faça varredura geral sem justificar.
- Comece por refinamento e plano sem alteração de código; siga os gates do Playbook.
- Antes de uma escrita, delimite arquivos, comportamento esperado, testes e condição de parada.
- Não faça ações destrutivas, mudança de dependência, deploy ou merge sem autorização humana conforme políticas corporativas.
- Se algum campo estiver `PREENCHER`, não invente o valor; verifique build/código ou pergunte.
- Nunca copie segredos ou dados reais de clientes para prompts, logs ou fixtures.
